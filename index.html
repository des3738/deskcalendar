DeskCalendar

Google 캘린더를 바탕화면에 띄워 주는 Windows 위젯

DeskCalendar는 개인용 Windows 바탕화면 위젯입니다. 사용자의 Google 캘린더 일정을 월간 달력으로 보여 주고, 위젯에서 바로 일정을 추가·수정·삭제할 수 있습니다.

  • 월간 달력과 다가오는 일정 목록 표시
  • 일정 추가·수정·삭제 (Google Calendar API 사용)
  • 광고 없음, 사용 기록 수집 없음
  • 모든 데이터는 사용자 PC에만 저장

DeskCalendar is a personal Windows desktop widget that shows your Google Calendar events and lets you create, edit and delete them. It has no ads and no analytics, and stores data only on your own computer.
